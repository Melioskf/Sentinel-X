# Code of Conduct

## Our standard

Contributors and maintainers are expected to communicate professionally, respectfully, and in good faith. Technical disagreement is welcome; harassment, threats, discrimination, intimidation, personal attacks, doxxing, and deliberately disruptive behavior are not.

## Scope

This applies to project repositories, issues, pull requests, discussions, documentation, and other project spaces.

## Enforcement

Maintainers may remove content, close conversations, reject contributions, or restrict participation when behavior violates these standards. Decisions should be proportionate, documented, and focused on maintaining a safe and productive project.

## Reporting

For conduct concerns, contact the project maintainer through the GitHub repository. For security vulnerabilities, do **not** use a public issue; follow `SECURITY.md` instead.
